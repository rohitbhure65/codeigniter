Email & Password Validation Error Demo

This CodeIgniter CRUD application now includes comprehensive validation with user-friendly error messages.

🔐 Login Form Validation

The login form now validates email and password with specific error messages:

Please enter a valid email address
Password must be at least 8 characters long

Login Error Scenarios:

  • Empty email → "Email is required"
  • Invalid email format → "Please enter a valid email address"
  • Email not found → "No account found with this email address"
  • Empty password → "Password is required"
  • Short password → "Password must be at least 8 characters long"
  • Wrong password → "Incorrect password"

📝 Registration Form Validation

The registration form includes enhanced validation with preserved form data:

This email is already registered
Password must contain at least one uppercase letter
Phone must be exactly 10 digits

Registration Error Scenarios:

  • Duplicate email → "This email is already registered"
  • Weak password → Must contain uppercase, lowercase, and number
  • Invalid phone → "Phone must be exactly 10 digits"
  • Missing fields → Specific error for each required field

🎨 Enhanced User Experience

  • Visual error indicators with red borders on invalid fields
  • Styled error messages with background colors and icons
  • Form data preservation - users don't lose their input
  • Real-time validation feedback
  • Specific error messages instead of generic ones

💻 Implementation Details

Controller Changes:

// Custom validation in auth() method if (!$user) { $data["validation_errors"] = [ "email" => "No account found with this email address", ]; $this->load->view("users/login", $data); return; } if (!password_verify($password, $user->password)) { $data["validation_errors"] = ["password" => "Incorrect password"]; $this->load->view("users/login", $data); return; }

View Changes:

<input type="email" name="email" class="<?= isset($validation_errors["email"]) ? "error-input" : "" ?>"> <?php if (isset($validation_errors["email"])): ?> <p><?= $validation_errors["email"] ?></p> <?php endif; ?>

🚀 Password Security Features

Registration now includes comprehensive password validation:

  • Minimum 8 characters required
  • Must contain at least one uppercase letter
  • Must contain at least one lowercase letter
  • Must contain at least one number
  • Passwords are hashed using bcrypt
